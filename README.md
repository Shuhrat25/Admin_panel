# Admin Workspace (User Management System)

**🔗 Live Demo (Хостинг):** [Вставить ссылку на рабочий проект здесь]

## 📌 Описание проекта
Полнофункциональное веб-приложение для управления пользователями. Проект представляет собой панель администратора с системой регистрации, авторизации и интерактивной таблицей для управления учетными записями. Разработано с акцентом на безопасность, проверку статусов "на лету" и строгий корпоративный UI-дизайн.

## 🚀 Ключевой функционал
*   **Авторизация:** Регистрация новых пользователей с автоматическим хэшированием паролей (`bcrypt`) и защищенный доступ к панели управления.
*   **Проверка статуса "на лету":** Мгновенное прерывание сессии и редирект на страницу входа, если аккаунт текущего пользователя заблокирован или удален.
*   **Управление сессией:** Функция "Запомнить меня" с переключением между локальным хранилищем (на 3 часа) и сессионным.
*   **Массовые действия в таблице:** Выделение пользователей чекбоксами для групповой блокировки (Block), разблокировки (Unblock) и удаления (Delete).
*   **Поиск:** Интерактивная фильтрация таблицы по имени или e-mail.
*   **Сортировка:** Естественная сортировка (Natural Sort) по всем доступным колонкам таблицы.
*   **Пагинация:** Настраиваемое количество строк на странице (10, 25, 50, 100) с удобной навигацией.
*   **UI/UX:** Адаптивный дизайн без излишних анимаций, единая панель инструментов и переключатель темной/светлой темы.

## 🛠 Технологический стек
*   **Frontend:** React (Vite), React Router DOM, React Bootstrap.
*   **Backend:** Node.js, Express, `bcrypt`, `cors`.
*   **Database:** PostgreSQL (уникальность e-mail реализована на уровне ядра БД через `UNIQUE INDEX`).

## ⚙️ Инструкция по локальному запуску

Для запуска проекта на локальном компьютере потребуется установленный Node.js и PostgreSQL.

### 1. Клонирование репозитория
```bash
git clone [ВСТАВИТЬ_ССЫЛКУ_НА_РЕПОЗИТОРИЙ]
cd [ИМЯ_ПАПКИ_ПРОЕКТА]
```

### 2. Настройка базы данных (PostgreSQL)
Создайте базу данных user_management и выполните следующий SQL-скрипт:
```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) NOT NULL,
    password VARCHAR(255) NOT NULL, 
    status VARCHAR(20) DEFAULT 'unverified',
    last_login TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE UNIQUE INDEX idx_users_email ON users(email);
```

### 3. Запуск Backend-сервера
В новом терминале перейдите в папку backend:
```bash
cd backend
npm install
```
Убедитесь, что в файле db.js указан правильный пароль от вашей локальной БД, затем запустите сервер:
```bash
node server.js
```
Сервер будет доступен на `http://localhost:3000`.

### 4. Запуск Frontend-клиента
В новом терминале перейдите в папку frontend:
```bash
cd frontend
npm install
npm run dev
```
Клиент запустится в браузере по адресу `http://localhost:5173`.
